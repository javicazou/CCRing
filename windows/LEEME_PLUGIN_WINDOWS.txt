URing @VERSION@ - Monstri Audio - WINDOWS (64 bits, Windows 10/11)

INSTALAR
1. Descomprime este zip.
2. Clic derecho en INSTALAR_PLUGIN.bat -> "Ejecutar como administrador".
   (o copia a mano la carpeta URing.vst3 en C:\Program Files\Common Files\VST3\)
3. Ableton Live: Preferencias -> Plug-ins -> activar "Use VST3 Plug-in System Folder"
   y Re-escanear. URing aparece en Plug-ins -> VST3.

URing.exe es la version suelta (sin DAW): se abre con doble clic.
Si Windows muestra "Windows protegio su PC": Mas informacion -> Ejecutar de todas formas
(el programa no esta firmado con un certificado comercial).

izquierda) -> LANGUAGE -> ESPANOL.
