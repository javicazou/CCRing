URing @VERSION@ - Monstri Audio - WINDOWS (64-bit, Windows 10/11)

INSTALL
1. Unzip this file.
2. Right-click INSTALAR_PLUGIN.bat -> "Run as administrator".
   (or copy the URing.vst3 folder by hand into C:\Program Files\Common Files\VST3\)
3. Ableton Live: Settings -> Plug-Ins -> enable "Use VST3 Plug-in System Folder"
   and Rescan. URing appears under Plug-Ins -> VST3.

URing.exe is the standalone version (no DAW needed): double-click to open it.
If Windows shows "Windows protected your PC": More info -> Run anyway
(the program is not signed with a commercial certificate).

LANGUAGE
URing starts in English. For Spanish: click the URing logo (top left) ->
LANGUAGE -> ESPANOL.
